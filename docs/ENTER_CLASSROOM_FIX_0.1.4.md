# Windows 0.1.4 进入课堂修复

日期：2026-10-10。

## 问题与原因

旧版在进入课堂时显示“进入课堂失败（ERR_ABORTED）”，即使官方页面已经自行跳到同一课堂的题目子页面。实际 Electron 测试通过课堂入口中的 `location.replace` 重现完整提示，随后仍收到一次有效的官方签到回执并连接课堂。

`loadURL` 的原始加载被页面跳转取消，Promise 拒绝被通用错误提示当作进入课堂失败。旧版的 `did-fail-load` 回调已经排除 -3，但未覆盖 Promise 拒绝。

## 修复

- 在发起导航前监听主框架完成、失败和关闭事件；原加载被取消时等待后续加载结果。
- 进入课堂必须完成同一来源、同一完整课堂 ID 的入口或子路由加载。其他课堂不算成功。
- 真正的主框架网络错误仍显示失败；20 秒无结果则停止加载并提示超时。失败后取消待连接课堂，不重放签到请求。
- 子框架加载错误不覆盖课堂状态。官方弹出页面在同一隔离浏览器内加载，并处理跳转失败。
- 配置和提交记录的存储格式保持不变。
